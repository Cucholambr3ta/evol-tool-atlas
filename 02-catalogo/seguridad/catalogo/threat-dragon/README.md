## Función

Modelado de amenazas mediante diagramas y asociación de mitigaciones, con marcos STRIDE, LINDDUN y otros compatibles.

## Utilidad EVOL

Preparar modelos de amenazas para Evol Guard, Core, Memory Engine y sus canales IPC. No se presume integración automática ni instalada.
