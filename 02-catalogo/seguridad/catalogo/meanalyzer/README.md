## Función

Herramienta de análisis de firmware Intel Engine y Graphics. Examina familias ME/CSME, TXE y SPS, entre otras.

## Aplicación a EVOL

Inspección documental de componentes de firmware Intel en entornos de laboratorio; no requiere modificar el firmware del equipo.
