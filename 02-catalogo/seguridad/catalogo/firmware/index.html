Categoría 01 · Seguridad

Firmware

Herramientas contrastadas individualmente para análisis de firmware. Ninguna está declarada como instalada en el laboratorio.

Alcance de esta entrega

Tres fuentes accesibles contrastadas; una referencia excluida del navegador operativo por repositorio original no disponible. Esta categoría no es un inventario del sistema local.

Herramientas admitidas

  • Distribución oficial verificada · 1.312.0 r378
    ME Analyzer

    Herramienta de análisis de firmware Intel Engine y Graphics. Examina familias ME/CSME, TXE y SPS, entre otras.

  • PyPI y fuente verificados · 1.17
    UEFI Firmware Parser

    Módulo y utilidad CLI de Python para analizar estructuras UEFI, cápsulas, volúmenes y otras estructuras de firmware.

  • Referencia histórica, no validada para producción · sin versión upstream confirmada
    Firmware Mod Kit

    Colección histórica de scripts para extraer y modificar imágenes de firmware, preservada en un repositorio exportado desde Google Code.

Exclusiones

Firmwalker: la fuente registrada en el expediente documental v2.3.2, https://github.com/craigz28/firmwalker, devolvió 404 en la comprobación directa del 2026-11-22. No se presenta un fork como sustituto sin evidencia de procedencia. No tiene ficha navegable en este lote.

Fuente comparativa: Guía documental v2.3.2; ver registro de validación.
