## Herramientas
- **Matroschka** · HISTORICO: Herramienta Python para explorar técnicas esteganográficas con imágenes.
- **pngcheck** · EVALUACION: Validación de estructura y comprobaciones CRC de PNG, MNG y JNG.
- **SilentEye** · HISTORICO: Aplicación gráfica de esteganografía en imágenes y sonidos.
- **StegCracker** · ARCHIVADO: Herramienta histórica para pruebas controladas de recuperación de datos protegidos en archivos esteganográficos.
- **stegdetect** · HISTORICO: Detección heurística de ciertos formatos de contenido oculto en imágenes.
- **StegoLeggo** · HISTORICO: Herramienta de experimentación esteganográfica.
- **Stegseek** · EVALUACION: Herramienta de laboratorio para análisis de medios creados con steghide.
- **Stepic** · LEGADO: Proyecto Python histórico de esteganografía de imágenes, disponible como paquete en PyPI.
- **zsteg** · EVALUACION: Detección de datos ocultos en archivos PNG y BMP.
