# Registro de validación — DoS y pruebas de carga

**Fuente original:** Guía documental v2.3.2.

**Admitidas:** 17/27. **Excluidas:** 10.

## Excluidas del catálogo navegable

- **42zip:** El expediente no acredita un repositorio o distribución primaria vigente: sin respuesta HTTP (conexion_cortada): posible indisponibilidad temporal
- **davoset:** Sitio histórico; código o distribución vigente no confirmados.
- **dnsdrdos:** Página genérica de múltiples herramientas; no hay enlace primario individual comprobado.
- **iaxflood:** El expediente no acredita un repositorio o distribución primaria vigente: HTTP 200, pero el contenido no identifica la herramienta
- **nkiller2:** El expediente no acredita un repositorio o distribución primaria vigente: HTTP 301 sin contenido verificable
- **shitflood:** El expediente no acredita un repositorio o distribución primaria vigente: GitHub responde 404: repositorio eliminado o privado
- **slowloris:** El expediente no acredita un repositorio o distribución primaria vigente: sin respuesta HTTP (timeout): posible indisponibilidad temporal
- **synflood:** El expediente no acredita un repositorio o distribución primaria vigente: el dominio no resuelve (DNS): retirado o inexistente
- **tcgetkey:** El expediente no acredita un repositorio o distribución primaria vigente: un intersticial anti-bots impide comprobar el destino (packetstorm.news)
- **thc-ssl-dos:** El expediente no acredita un repositorio o distribución primaria vigente: HTTP 404: el recurso ya no existe en el servidor

## Condiciones y límites

Disponibilidad documental verificada en las fechas registradas, no verificación funcional. Estado de mantenimiento no determinado salvo evidencia explícita. No son herramientas instaladas ni aprobadas por EVOL.
