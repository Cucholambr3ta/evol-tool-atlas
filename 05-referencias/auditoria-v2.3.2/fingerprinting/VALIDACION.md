# Registro de validación — Fingerprinting

**Fuente original:** Guía documental v2.3.2.

**Admitidas:** 19/30. **Excluidas:** 11.

## Excluidas del catálogo navegable

- **asp-audit:** Lista de correo histórica, no canal de descarga comprobado.
- **blindelephant:** Página antigua: no se confirmó release o archivo distribuido en esta revisión.
- **fl0p:** El expediente no acredita un repositorio o distribución primaria vigente: HTTP 200, pero el contenido no identifica la herramienta
- **ftpmap:** El expediente no acredita un repositorio o distribución primaria vigente: HTTP 404: el recurso ya no existe en el servidor
- **htrosbif:** El expediente no acredita un repositorio o distribución primaria vigente: GitHub responde 404: repositorio eliminado o privado
- **httprint:** Sitio histórico, descarga comprobable no confirmada.
- **kolkata:** El expediente no acredita un repositorio o distribución primaria vigente: certificado TLS inválido: no se puede confiar en el destino
- **ntp-fingerprint:** El expediente no acredita un repositorio o distribución primaria vigente: sin respuesta HTTP (timeout): posible indisponibilidad temporal
- **sinfp:** El expediente no acredita un repositorio o distribución primaria vigente: redirige a otro dominio que no menciona la herramienta; su relación con el proyecto no se pudo comprobar (cambio de dominio registrable (metacpan.org -> cpan.org))
- **smtpmap:** Página genérica antigua, distribución verificable no confirmada.
- **smtpscan:** El expediente no acredita un repositorio o distribución primaria vigente: un intersticial anti-bots impide comprobar el destino (packetstorm.news)

## Condiciones y límites

Disponibilidad documental verificada en las fechas registradas, no verificación funcional. Estado de mantenimiento no determinado salvo evidencia explícita. No son herramientas instaladas ni aprobadas por EVOL.
