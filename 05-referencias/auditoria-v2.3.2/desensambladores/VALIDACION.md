# Validación — Desensambladores

Fuente: Guía documental v2.3.2.

Admitidas: 12 / 17.

## Excluidas

- **exe2hex:** Repositorio real, pero la función documentada es transferencia de archivos, no desensamblado; necesita reclasificación.
- **python-lief:** Empaquetado Python del mismo proyecto LIEF; unificado en su ficha canónica.
- **python2-capstone:** Paquete Python 2 obsoleto; no se acredita un canal actual para esta variante.
- **python2-pcodedmp:** Variante Python 2 obsoleta; ficha canónica actual corresponde a pcodedmp.
- **radare2-unicorn:** La fuente consultada corresponde a un repositorio de extras/graveyard, sin validar la disponibilidad del plugin como herramienta independiente.

## Límites

Fuentes accesibles ≠ instalación, compatibilidad o mantenimiento garantizados.
