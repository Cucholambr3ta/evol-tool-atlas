# Registro de validación — Bluetooth

**Fuente original:** Guía documental v2.3.2.

**Admitidas:** 9/26. **Excluidas:** 17.

## Excluidas del catálogo navegable

- **bluebugger:** El expediente no acredita un repositorio o distribución primaria vigente: un intersticial anti-bots impide comprobar el destino (packetstorm.news)
- **bluefog:** El expediente no acredita un repositorio o distribución primaria vigente: sin URL en tools.html ni en el PKGBUILD
- **blueprint:** El expediente no acredita un repositorio o distribución primaria vigente: HTTP 206, pero el contenido no identifica la herramienta
- **bluescan:** Artículo divulgativo, sin descarga oficial comprobada.
- **bluesnarfer:** Página histórica, distribución y licencia no verificadas.
- **braces:** El expediente no acredita un repositorio o distribución primaria vigente: el dominio no resuelve (DNS): retirado o inexistente
- **bss:** El expediente no acredita un repositorio o distribución primaria vigente: HTTP 206, pero el contenido no identifica la herramienta
- **bt_audit:** Página antigua con identidad, artefacto descargable y licencia no revalidados.
- **btcrack:** El expediente no acredita un repositorio o distribución primaria vigente: redirige a un destino que no es el recurso (la redirección pierde la ruta del recurso (/_en/security_tools_btcrack.php -> raíz))
- **btscanner:** El expediente no acredita un repositorio o distribución primaria vigente: HTTP 206, pero el contenido no identifica la herramienta
- **carwhisperer:** Proyecto histórico: distribución verificable no confirmada en esta revisión.
- **ghettotooth:** El expediente no acredita un repositorio o distribución primaria vigente: el dominio no resuelve (DNS): retirado o inexistente
- **hidattack:** Página antigua sin canal de distribución confirmado en esta revisión.
- **obexstress:** Página histórica sin distribución actual comprobada.
- **redfang:** El expediente no acredita un repositorio o distribución primaria vigente: un intersticial anti-bots impide comprobar el destino (packetstorm.news)
- **spooftooph:** Página histórica sin artefactos comprobados.
- **tbear:** El expediente no acredita un repositorio o distribución primaria vigente: redirige a otro dominio que no menciona la herramienta; su relación con el proyecto no se pudo comprobar (cambio de dominio registrable (freshmeat.net -> sf.net))

## Condiciones y límites

Disponibilidad documental verificada en las fechas registradas, no verificación funcional. Estado de mantenimiento no determinado salvo evidencia explícita. No son herramientas instaladas ni aprobadas por EVOL.
