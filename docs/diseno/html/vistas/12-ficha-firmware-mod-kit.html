Descripción documental

Colección histórica de scripts para extraer y modificar imágenes de firmware, preservada en un repositorio exportado desde Google Code.

Uso documentado para EVOL: Consultar formatos antiguos de firmware y técnicas de análisis en un entorno desechable. No se incorpora como dependencia operativa de Evol OS.

Advertencias de mantenimiento, compatibilidad y uso seguro

Esta ficha es estrictamente documental. La aplicación no descarga, instala ni ejecuta ninguna herramienta del catálogo.

  • La presencia del repositorio no implica mantenimiento ni seguridad del código.
  • No se instaló ni ejecutó esta herramienta sobre CachyOS.
  • No se infiere una versión upstream actual a partir del identificador del paquete de referencia.
  • El contenido modifica firmware y puede requerir herramientas antiguas. No usar para modificar imágenes reales ni instalar en el host sin auditoría independiente.
  • La versión registro documental 0.99.r119.gc72f45d no debe mostrarse como versión upstream actual. Sin release oficial moderno comprobado.
