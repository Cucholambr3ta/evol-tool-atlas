Descripción documental

Aplicación de modelado de amenazas para diagramas, límites de confianza, flujos de datos y mitigaciones.

Uso documentado para EVOL: Modelar amenazas de Evol Guard, Evol Core y Memory Engine antes de implementar cambios sensibles. Puede apoyar sesiones de revisión de arquitectura; no sustituye pruebas de seguridad.

Advertencias de mantenimiento, compatibilidad y uso seguro

Esta ficha es estrictamente documental. La aplicación no descarga, instala ni ejecuta ninguna herramienta del catálogo.

  • La versión de la guía (2.2.0) es histórica. OWASP registra release 2.6.2. No se ha descargado ni ejecutado la aplicación y no se recomienda publicar diagramas confidenciales en servicios de terceros.
  • Se validaron páginas del proyecto y release, no el checksum del ejecutable descargado
  • Estado de instalación local desconocido.
  • Ningún procedimiento se ejecutó en el Atlas; la guía es documental.
  • La aplicación ayuda a razonar sobre amenazas; no detecta vulnerabilidades ni sustituye pruebas de seguridad.
  • En la aplicación web, el almacenamiento en proveedores (GitHub, Bitbucket, GitLab, Google Drive) deposita los modelos en servicios de terceros.

Guía técnicaCasos de uso

Casos de uso propuestos (2)

  • CU-TD-01 · Modelo STRIDE de un servicio con IPC local — Representar procesos, almacén, actores y flujos del componente con sus límites de confianza y registrar amenazas STRIDE por elemento antes de implementar el cambio. (BAJO · Exposición del diseño si el modelo se guarda fuera del repositorio privado.)
  • CU-TD-02 · Revisión de privacidad con LINDDUN de un flujo de datos personales — Registrar amenazas de privacidad LINDDUN sobre los flujos y almacenes que tratan datos personales y vincular cada una a una medida de minimización o protección. (MEDIO · El modelo contiene descripciones de datos personales y debe tratarse como confidencial.)

Casos documentados, no ejecutados por el Atlas. Requieren autorización, entorno aislado y registro de evidencia.
