Paquete de auditoría visual

Qué es: capturas estáticas de la PWA EVOL Tool Atlas renderizada por un navegador real, más las guías y casos del lote E3-01 en HTML. Las capturas no ejecutan JavaScript: muestran el DOM y el estilo tal como los renderizó la app. Los datos del catálogo son reales; los estados de usuario (favoritos, búsquedas, tema, conexión, tamaño de pantalla) están simulados y se indican en cada página con un recuadro amarillo.

Cómo funciona la app

  1. Datos: catalogo.json (49 categorías, 2.137 herramientas, 741 exclusiones) se transforma con npm run generate:data en índices y fragmentos por categoría (data/catalog-index.json, data/categories/*.json) que incluyen los recursos de cada ficha (guía, skill, casos, evidencias).
  2. Navegación: aplicación de una sola página con rutas por hash: #/ inicio, #/categorias, #/categoria/<slug>, #/buscar?q=…, #/herramienta/<id>, #/favoritos, #/offline, #/acerca.
  3. Ficha: muestra metadatos, estado de evidencia y botones a los recursos técnicos; los recursos se abren como archivos del catálogo (en este paquete, como HTML).
  4. Estado local: favoritos y tema se guardan en localStorage del navegador; no hay cuentas ni servidor.
  5. Sin conexión: un service worker precarga la app y la página #/offline descarga el catálogo completo a la caché del navegador.

Recorrido sugerido para la auditoría

  1. Entrada: Inicio → Categorías → Modelado de amenazas.
  2. Ficha enriquecida: Threat Dragon → botón «Guía técnica» → guía HTML y casos.
  3. Comparar con una ficha no enriquecida: Firmware Mod Kit y con una de la etapa 2: Semgrep.
  4. Búsqueda: con resultados y sin resultados.
  5. Estado de usuario simulado: favoritos, descarga offline, sin conexión.
  6. Variantes: tema oscuro y móvil; errores: ruta y herramienta inexistentes.

Limitaciones del paquete

  • Las capturas HTML no tienen JavaScript: botones, filtros y el buscador no responden. Las imágenes PNG de capturas/ muestran el render exacto.
  • Los enlaces a vistas no incluidas aparecen desactivados (atributo data-ruta-original).
  • Se eliminó la cabecera Content-Security-Policy y el manifiesto PWA de las capturas para que funcionen abiertas desde disco.
  • La vista de descarga offline muestra un estado intermedio real a los 2 s; no representa una descarga completa.
  • Las guías se convirtieron de Markdown con un conversor propio limitado a encabezados, párrafos, listas, tablas, citas y código; el contenido es el de los archivos fuente cuyo hash se indica.
