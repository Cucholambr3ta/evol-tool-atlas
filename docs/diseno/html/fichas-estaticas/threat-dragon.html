OWASP Threat Dragon

Aplicación de modelado de amenazas para diagramas, límites de confianza, flujos de datos y mitigaciones.

Estado verificado

Repositorio y release oficiales

Fecha: 2026-11-22

Versión oficial

2.6.2

Instalación en CachyOS: no verificada

Uso en EVOL

Modelar amenazas de Evol Guard, Evol Core y Memory Engine antes de implementar cambios sensibles. Puede apoyar sesiones de revisión de arquitectura; no sustituye pruebas de seguridad.

Permite documentar las amenazas con marcos como STRIDE y LINDDUN, pero no implica que exista integración automática con Evol Guard.

Limitaciones

La versión de la guía (2.2.0) es histórica. OWASP registra release 2.6.2. No se ha descargado ni ejecutado la aplicación y no se recomienda publicar diagramas confidenciales en servicios de terceros.
